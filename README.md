# Handwritten Digit Recognition

## Project Overview

This project is a Machine Learning application that recognizes handwritten digits from images.

The model learns patterns from handwritten digit images and predicts the digit represented by the input image.

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- TensorFlow
- Keras
- Jupyter Notebook

## Features

- Recognizes handwritten digits.
- Classifies digits from 0 to 9.
- Preprocesses image data before training.
- Uses a neural network for digit classification.
- Evaluates the trained model using test data.
- Predicts handwritten digits from input images.

## Dataset

The project uses a handwritten digit dataset containing images representing digits from 0 to 9.

The dataset is divided into training and testing data so that the model can learn from the training images and then be evaluated on unseen test images.
